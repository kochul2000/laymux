# 0367. Android 미변경 릴리스에는 기존 APK를 같은 파일명으로 재첨부한다

- Status: Proposed
- Date: 2026-10-31
- Source: 사용자 요구(최신 APK를 찾기 어려우므로 변경 없는 APK는 빌드 없이 새 릴리스에 복사), [릴리스 정책](../release-policy.md), [ADR-0223](0223-android-release-advances-only-with-apk.md)
- 관계: ADR-0223의 APK 재첨부 금지만 대체한다. APK 버전·채널·빌드 입력 게이트는 유지한다.

## Context

Android 네이티브 변경이 없으면 서명 APK 빌드와 채널 전진을 생략한다. 최신 데스크톱 릴리스에 APK가 없어서 사용자는 과거 릴리스를 찾아야 한다. APK를 매번 새 버전으로 빌드하는 것은 불필요한 업데이트와 서명 작업을 만든다.

재첨부를 허용하되 기존 APK의 버전과 현재 데스크톱 태그를 혼동시키지 않아야 한다. 안정판과 beta는 각 Android 채널의 검증된 원본을 사용해야 하며, 재첨부를 신규 Android 빌드로 인식해서도 안 된다.

## Decision

**Android 입력이 바뀌지 않은 릴리스에는 현재 Android 채널의 APK·체크섬을 원래 파일명과 바이트 그대로 재첨부하고 원본 정보를 표시한다.**

- 기존 `publish_android=false`의 소스 변경 검사를 유지한다. 이 검사에 사용한 Android 채널 매니페스트를 같은 prepare job의 복사 단계에 전달한다. stable 릴리스는 Android stable, beta 릴리스는 Android beta를 사용한다.
- 대상은 draft 생성 응답의 release ID로 식별하고 최초·업로드 후 REST 조회도 같은 ID를 사용한다. 아직 공개되지 않은 태그를 대상으로 REST tag 조회를 하지 않는다.
- 원본 매니페스트의 버전·versionCode·저장소·원본 태그·APK와 체크섬 URL을 기존 검증기로 검사한다. 원본 체크섬과 APK의 SHA-256이 같을 때만 첨부한다. APK·체크섬 이름에 새 데스크톱 버전을 넣지 않으며 다시 서명하지 않는다.
- 새 릴리스의 원본 안내 JSON과 릴리스 설명에 실제 Android 버전·원본 릴리스·SHA-256을 남긴다. 이미 같은 이름의 첨부가 있으면 내용이 동일한 경우만 재실행을 허용하며 덮어쓰지 않는다. 복사 실패는 prepare 실패로 처리해 정상 자동 발행을 막는다.
- Android versionName/versionCode와 두 Android 채널 파일은 그대로 유지한다. 부트스트랩은 기존처럼 해당 릴리스 태그의 버전과 APK 파일명이 일치하는 원본 Android 릴리스만 선택한다. 재첨부된 과거 버전 APK는 seed가 아니다.
- 명시적 `publish_android=true`의 빌드·테스트·signer fingerprint 검증과 게시 게이트는 유지한다. 공개 릴리스의 수동 보충은 명시적 옵션과 입력 변경 재검증 아래 허용하며 같은 원본·체크섬·이름 보존을 적용한다.

## Alternatives Considered

- APK를 매번 새 버전으로 다시 빌드: Android 변경이 없어도 재설치 후보와 서명 작업을 만든다.
- 원본 링크만 설명에 추가: 최신 릴리스 첨부에서 APK를 바로 찾고 싶다는 요구를 충족하지 않는다.
- 새 데스크톱 버전으로 APK 파일명이나 채널을 변경: 내부 APK 버전 및 원본 태그 불변식과 어긋난다.

## Consequences

사용자는 최신 릴리스 첨부에서 APK를 받을 수 있다. 같은 APK가 여러 릴리스에 저장되는 비용과 원본·복사본 검증 책임이 추가된다. Android 변경 누락은 계속 소스 입력 게이트가 거부한다. 기존 공개 릴리스에는 사용자 요청 범위에서 보충할 수 있다.

검증은 stable/beta 원본 선택, 원래 파일명·바이트·체크섬 유지, 잘못된 출처·손상·동명 충돌 거부, 멱등 재실행, workflow 게이트 순서, 원본만 선택하는 부트스트랩을 포함한다. 앱·APK 실행 코드나 버전은 바뀌지 않으므로 이 자동화 변경만으로 앱 릴리스를 추가하지 않는다.

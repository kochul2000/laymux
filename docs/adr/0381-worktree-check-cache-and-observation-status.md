# 0381. 워크트리 검사는 대상별로 공유하고 관측 공백을 요약한다

- Status: Accepted
- Date: 2026-11-09
- Source: 사용자 요청(반복 검사·진행 수 초기화·숨김과 PTY 경고의 기준 불명확, 대용량 파일 목록의 8 MiB 검사 실패 수정), ADR-0343, ADR-0345
- 관계: ADR-0345의 재검사 정책을 공유 작업과 짧은 메모리 캐시로 구체화하고, ADR-0343의 Git 출력 제한을 파일·인덱스 목록의 스트리밍 집계로 확장한다.

## Context

뷰 이탈과 터미널 복원 이벤트가 진행 중 검사를 취소하고 처음부터 다시 실행해 진행 수가 후퇴했다. 전역 사용 관측 경고는 모든 저장소의 목록 위에 펼쳐졌다. 숨긴 복원 대상과 연결된 터미널의 구분도 드러나지 않았다. 반복 진입 비용을 줄이면서 저장된 CWD를 현재 실행 경로로 오인하거나 관측 실패를 미사용으로 처리하지 않아야 한다. Windows·WSL 실행 환경 격리와 기존 제거 보호는 유지한다.

## Decision

**PC 워크트리뷰는 동일 대상의 진행 중 검사를 공유하고 최근 결과를 재사용하며 관측 공백은 제거 보류 이유와 함께 접어 표시한다.**

- 프런트엔드 메모리가 캐시를 소유한다. 키는 요청 CWD·원본 terminal ID·CWD 유지 모드와 사용 상태 무효화 신호다. 배포판이 다른 동일 POSIX 경로를 합치지 않는다.
- 작업은 뷰 이탈과 무관하게 완료하고 내용 검사 동시성 3개를 유지한다. 완료 결과는 30초, 최대 12대상만 보유한다. 조회 실패는 재사용하지 않고 수동 갱신은 캐시를 우회한다. TTL은 재진입 시 판정하며 주기 폴링하지 않는다.
- 등록·준비·세대·제거와 실제 CWD 이동에 의한 연속 사용 상태 변경은 현재 검사를 완료한 뒤 최신 신호 한 번으로 합쳐 재검사한다. 출력·제목·활동은 신호에서 제외한다. 대기 즉시 과거 제거 적격성을 무효화한다. 진행 수는 현재 작업의 완료 수를 유지하고 후속 검사 예정을 표시한다.
- 목록 캐시는 참고용 관측이다. 상세는 항상 최신 검사, 제거는 기존 backend의 실행 직전 재검증을 수행한다. 숨김·저장·연결 대기 대상도 제거 보호에 포함한다.
- 경고는 기본 접힘 요약과 높이가 제한된 상세로 표시한다. 전역 관측 실패가 해당 저장소의 실제 사용을 증명하지 않는다는 설명을 함께 둔다.
- Git 검사가 완료됐으나 사용 관측이 불완전한 `usage_unknown`은 `사용 상태 미확인 · 제거 보류`로 표시한다. 실제 Git·조회 오류의 `검사 실패` 표시와 구분하며 제거 보호는 유지한다.
- 데몬 경고는 inventory가 관측한 화면 연결 대기·복원 대상 없음·다른 클라이언트 연결·종료 확인 대기를 구분하고 제공된 child PID를 표시한다. PID 표시는 관측 식별자이며 프로세스의 현재 CWD를 보증하지 않는다.
- 파일 상태와 인덱스 목록은 Git stdout의 NUL 구분 레코드를 스트리밍 집계한다. 전체 목록의 누적 크기로 검사를 실패시키지 않는다. 단일 레코드·미리보기 경로 합계·stderr는 각각 8 MiB로 제한하고 파일 미리보기는 기존 최대 200개를 유지한다. 개수와 제거 차단 사유는 미리보기 제한과 무관하게 끝까지 계산한다. 나머지 Git 출력의 8 MiB 제한과 명령당 30초 제한은 유지한다. 잘린 레코드·비정상 형식·Git 실패·시간 초과는 완료된 검사로 취급하지 않는다.
- 기존 Automation `POST /api/v1/ui/worktrees`에 `status`(표시 상태 읽기), `disclosure`(`section: warnings|criteria`, `open: boolean`)를 추가한다. 마운트된 pane만 대상으로 하며 제거 액션은 추가하지 않는다.

## Alternatives Considered

- 매번 재조회: 화면 왕복마다 같은 비용이 발생하고 진행 중 작업을 버린다.
- 저장소 경로만으로 무기한 캐시: WSL 환경과 원본 세션을 혼동하고 외부 변경을 오래 숨긴다.
- 매 이벤트마다 취소: 긴 검사가 끝나지 못한다.
- 불명확한 PTY 무시: 연결 전 실제 실행 세션을 놓쳐 제거 보호를 약화한다.
- 전체 출력 상한만 늘리기: 저장소 크기에 따라 메모리와 실패 지점이 계속 증가한다. ignored 디렉터리를 한 항목으로 축약하거나 기본 워크트리의 검사를 생략하기는 파일 수와 상세 정보의 의미를 바꾸므로 채택하지 않는다.

## Consequences

화면 재진입은 작업을 이어받는다. 외부 파일 변경은 최대 캐시 수명 동안 이전 결과로 보일 수 있어 수동 갱신과 최신 상세 검사를 유지한다. 공유 작업은 화면을 떠나도 잠시 자원을 사용한다. 대용량 출력은 누적 크기로 거부하지 않고 기존 시간 제한 안에서 끝까지 읽으므로 큰 트리의 파일 탐색 시간은 남는다. 캐시 수명·환경 격리·실패 복구·사용 상태 무효화와 작은 dock의 다수 경고 표시, 8 MiB를 넘는 실제 Git 출력·끝부분의 보호 플래그·불완전한 레코드 거부를 검증한다. 조회·표시 결함을 수정하면서 공개 Automation 계약에 상태 조회·설명 펼침 액션을 추가하므로 ADR-0281에 따라 버전 영향은 minor다.

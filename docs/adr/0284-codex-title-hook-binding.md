# 0284. Codex 공유 서버의 훅은 현재 TUI 제목의 대화 식별자로 연결한다

- Status: Accepted
- Date: 2026-09-29
- Source: 사용자 요구(제목을 통한 공유 서버 지원), [ADR-0283](0283-opt-in-hook-task-state.md), [훅 검증](../agent-hooks-validation.md)
- 관계: ADR-0283의 공유 서버 미지원 결정을 대체한다. 원시 상태 분리·기본 휴리스틱·종료 체크포인트 계약은 유지한다.

## Context

Codex 공유 서버는 처음 실행한 pane의 환경을 유지하며 다른 TUI의 대화도 처리한다. 훅의 pane ID와 토큰은 현재 소유자를 증명하지 못한다. 반면 각 TUI는 자신이 선택한 대화를 OSC 제목으로 출력한다. Codex 0.158의 `thread-id`(`session-id` 별칭)는 UUID 앞 29자와 `...`를 출력한다. 일반 대화 이름은 변경되거나 중복되므로 식별 근거가 아니다.

Windows·WSL dev에서 공유 서버 resume, `/new`, 훅 전체 ID와 제목 접두부 대조, 종료 후 셸 복귀를 확인했다. 현재 제목과 훅을 결합하되 과거 출력·모호한 접두부·죽은 TUI가 상태를 유지하지 못하게 해야 한다.

## Decision

**선택 설치한 Codex 제목 식별 항목을 현재 PTY에서 관찰하고, 같은 실행 환경의 훅 전체 ID로 유일하게 해소한 뒤 현재 TUI 생존과 설치 상태를 검증하여 훅 작업 상태에만 사용한다.**

- Codex 훅 설치는 해당 Windows/Linux/WSL 설정 루트의 `config.toml` 제목 항목 앞에 `app-name`, `thread-id`를 배치한다. 나머지 사용자 항목·주석·설정은 보존한다. 기본 제목 항목은 기존 Codex 기본값을 따른다. 관리 상태에는 제목 연결 설정 여부를 추가한다.
- 변경 전 항목과 설치한 항목을 별도 소유권 기록에 저장한다. 제거 시 현재 항목이 설치한 값과 일치할 때만 복원한다. 사용자 편집·손상은 덮어쓰지 않고 경고한다. 재설치·부분 실패 복구는 반복 가능하며 훅 제거는 제목 복원 실패와 독립적으로 가능하다.
- OSC 처리는 Rust의 기존 단일 패스에 둔다. 표시용 제목이나 복원된 화면을 다시 파싱하지 않는다. 식별 항목은 관리된 순서의 `codex | ID`만 인정하며 Codex 승인 대기 장식과 ID 뒤 제목 생성 spinner를 허용한다. 완전한 UUID 또는 0.158의 정확한 축약 형식만 인정한다.
- 현재 PTY 세대와 제목 식별 변경 revision을 묶는다. 다른 제목·빈 제목·셸 실행/프롬프트 경계·확인된 앱 종료에서 이전 식별자를 폐기한다. 파일 조회 전후에 같은 제목 관찰과 TUI 생존을 재검증한다. 제목만으로 실행 중인 앱이나 완료 상태를 만들지 않는다.
- 같은 provider·WSL 배포판의 관찰에서 전체 ID와 설정 루트가 하나로 확정되어야 한다. 모호함, 관찰 만료, subagent, 설치 해제, 제목 설정 해제, 프로세스 조회 실패는 기존 휴리스틱으로 돌아간다. 기존 프로세스 기반 정확한 귀속이 다른 대화를 지목하면 제목으로 덮어쓰지 않는다.
- 제목 연결은 훅 상태 snapshot의 대체 귀속 경로다. 종료 `/status`, 디스크 영속 복원점, 일반 세션 귀속 API의 정확성 계약을 바꾸지 않는다. 지원 여부가 불분명한 CLI 버전과 누락된 훅에는 기존 경로를 유지한다.

## Alternatives Considered

- `--no-daemon` 강제: 사용자의 공유 서버 실행 방식을 바꾸며 이미 제공되는 TUI 식별 경로를 활용하지 못한다.
- 훅이 제목을 직접 쓰기: 서버의 stdout은 현재 TUI의 PTY가 아니므로 pane을 선택할 수 없다.
- 제목의 Ready/Working만으로 작업 종료 판정: 상태 의미와 후속 훅 실행이 다르므로 기존 완료 감지 문제를 재발시킨다.
- 축약 ID를 그대로 저장하거나 최초 일치 선택: 충돌과 설정 루트 중복을 숨긴다. 전체 ID와 유일성을 확인한다.

## Consequences

공유 서버를 유지하면서 훅 감지를 사용할 수 있다. 외부 TOML 설정과 복원 소유권 관리 비용이 추가되고, 설치 후 실행 중인 TUI는 재시작해야 한다. 제목 출력 형식이 변경되면 연결은 보수적으로 실패하며 새 버전 검증이 필요하다. Windows·WSL 설치/제거, 사용자 설정 보존, 동일 서버의 여러 pane, 새 대화/resume, 제목 전환/초기화, 중복 접두부, PTY 교체, 셸 복귀를 검증한다. 호환되는 지원 환경 추가이므로 버전 영향은 minor다.

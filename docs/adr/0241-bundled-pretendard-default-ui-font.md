# 0241. 데스크톱 UI 기본 폰트로 Pretendard 가변 폰트를 내장한다

- Status: Accepted
- Date: 2026-09-08
- Source: 사용자 요구 — 가변 Pretendard 내장 및 기본값 지정; architecture/api-contracts.md §10·§15

## Context

설정과 메뉴의 기본 폰트가 OS에 설치된 Consolas·Fira Code 등 고정폭 폰트에 의존해 한글과 영문의 인상 및 배치가 환경마다 달랐다. 사용자는 설정 UX 개선에 이어 Pretendard 가변 폰트의 내장과 기본 적용을 요청했다. 오프라인 실행과 Windows·Linux 지원, 기존 폰트 선택의 보존이 필요하다. 터미널과 콘텐츠 뷰의 프로필 폰트 및 Remote는 범위 밖이다.

## Decision

데스크톱 UI의 기본 폰트는 앱에 동봉한 Pretendard 가변 WOFF2로 한다.

UI 기본 스택의 단일 정본은 기존 CSS 토큰으로 유지한다. 기존 빈 UI 폰트 설정은 내장 기본값을 뜻하며, 사용자가 명시한 폰트는 계속 우선한다. 네트워크나 OS 폰트 설치 없이 로컬 자산에서 로드하고, 로딩 중이거나 실패하면 sans-serif로 대체한다. 원본 글꼴 파일과 저작권·SIL OFL 1.1 라이선스를 함께 배포한다. 설정 스키마나 저장 데이터는 변경하지 않는다.

## Alternatives Considered

- OS 폰트만 사용: 번들 용량은 줄지만 환경별 표시 차이와 설치 의존이 남는다.
- CDN 로딩: 네트워크가 없는 환경에서 기본 글꼴을 보장할 수 없다.
- 정적 굵기별 파일: 사용하는 굵기가 늘 때 파일을 추가해야 한다. 사용자가 모든 굵기를 지원하는 가변 파일을 선택했다.

## Consequences

한글·영문 UI가 같은 글꼴로 표시되고 제목과 본문의 굵기를 한 파일로 지원한다. 원본 자산 약 2.06MB가 추가되며 버전 갱신 때 출처와 라이선스를 유지해야 한다. 기본 UI 글꼴의 폭 변화로 줄바꿈이 달라질 수 있으므로 설정의 일반·좁은 폭 레이아웃과 실제 폰트 로딩을 브라우저에서 검증한다. 사용자 지정 및 터미널 폰트는 보존한다. 배포 용량이나 지원 문자 요구가 달라지면 서브셋 여부를 재검토한다.

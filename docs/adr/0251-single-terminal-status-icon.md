# 0251. 터미널 활동은 다섯 종류 중 아이콘 하나로 표시한다

- Status: Accepted
- Date: 2026-09-17
- Source: 사용자 합의(내부 상태 신호 유지, 단일 아이콘, 중단은 대시, 상태 툴팁 제거, 미확인 알림 테두리 유지), PR #1052, architecture/data-flow.md §9, architecture/api-contracts.md §15.6
- Partially Supersedes: [ADR-0250](0250-terminal-task-state-and-notification-transitions.md)의 미확인·중단·결과 미관측 개별 표시 및 출력 활동·관측 지연 보조 표시 결정
- Preserves: ADR-0250의 작업·결과·관측·출력 분리, 알림 전이·중복 제거, 절전·clear 보호, PTY/세션 귀속

## Context

ADR-0250은 출력 애니메이션을 작업 완료와 혼동하지 않도록 내부 상태를 분리했다. 그러나 사용자 화면에도 각 축을 그대로 노출하면서 미확인 물음표와 모래시계·출력 파형·지연 시계가 함께 표시됐다. 사용자는 내부 판정의 고도화는 유지하되 UX는 이전처럼 간결하게 만들도록 요청했다. 실패와 중단은 내부에서도 다르며, 사용자 합의상 중단은 실패 X가 아니라 중립 대시로 표시한다.

범위는 Desktop 및 Remote 터미널 상태의 표현이다. 셸 통합 신호 수집, 작업 판정, 알림 문구·전이, 작업 중 개수, 절전과 clear 정책은 바꾸지 않는다.

## Decision

**터미널 상태는 `— / ⏳ / ! / ✓ / ✗` 중 하나만 표시하며, 세부 관측 신호는 상태 아이콘이나 툴팁으로 노출하지 않는다.**

- 입력 대기는 `!`, 진행 중은 `⏳`, 종료의 성공은 `✓`, 실패는 `✗`, 중단과 결과 없는 종료는 `—`로 표시한다.
- 작업 없음 또는 작업 미확인은 출력 활동이 있으면 `⏳`, 없으면 `—`로 표시한다. 이 모래시계는 표현이며 내부 running 상태의 증거가 아니다.
- 확인된 입력 대기·진행·종료는 출력 활동보다 우선한다. 종료 뒤 장식 출력으로 성공 표시가 모래시계로 되돌아가지 않는다. 관측 지연에는 마지막 상태의 단일 표시를 유지한다.
- 미확인 물음표, 중단·결과 미관측 전용 아이콘, 출력 파형, 지연 시계 및 상태 툴팁은 없앤다. 접근성 이름도 다섯 표시의 의미만 제공한다.
- 아직 읽지 않은 알림의 기존 네모 테두리와 포커스 진입·확인에 따른 읽음 처리는 유지한다. 알림 테두리는 작업 상태와 독립이다.
- 내부 상태와 Automation/Remote의 `taskState`, `taskResult`, `observation`, `outputActive`는 유지한다. Desktop과 Remote는 같은 순수 표시 함수를 사용하며, 표현 결과로 알림·절전·clear를 역추론하지 않는다. Windows·Linux 모두 동일하다.

## Alternatives Considered

- 내부 상태를 예전 단일 상태로 되돌리기: 작업 종료 증거·관측 실패·알림 중복 제거를 잃으므로 배제한다.
- 보조 아이콘 대신 툴팁으로 내부 신호 노출: 사용자가 툴팁도 불필요하다고 명시했으므로 배제한다.
- 중단을 실패 X로 합치기: 오류와 사용자 취소를 같은 실패로 보이게 하므로 사용자 합의대로 중립 대시를 택한다.
- 출력이 있으면 항상 모래시계: 승인 대기나 확인된 종료를 장식 출력이 덮을 수 있으므로, 출력 fallback은 작업 없음·미확인에만 적용한다.

## Consequences

아이콘 수와 시각적 잡음이 줄어든다. 대신 사용자는 아이콘만으로 중단·작업 없음·관측 부재·결과 없는 종료를 구분할 수 없으며, 모래시계가 실제 작업 진행을 증명하지 않을 수도 있다. 이는 합의된 표현의 단순화이며 내부 데이터와 보호 정책은 더 엄격한 의미를 계속 유지한다.

설정·세션 마이그레이션이나 의존성 추가는 없다. 표시 조합·Desktop/Remote 일치·알림 테두리·툴팁 부재를 검증하고 기존 알림/절전/clear 회귀 검증을 유지한다. 향후 별도 진단 UI가 필요하면 내부 신호를 그 표면에 노출하는 결정을 별도로 검토한다.

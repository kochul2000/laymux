# 0320. Remote 드로어는 페인과 워크스페이스의 스킵·숨김 열을 통일한다

- Status: Accepted
- Date: 2026-10-12
- Source: 사용자 요청 및 모바일 화면 승인, [api-contracts.md §13.3](../architecture/api-contracts.md), [ADR-0047](0047-remote-spatial-workspace-exclusions.md), [ADR-0153](0153-remote-hidden-item-visibility-controls.md), [ADR-0310](0310-remote-workspace-management-menu.md)
- Amends: ADR-0310의 숨김 진입점 통합. 이름 변경·템플릿 저장 관리 메뉴와 호스트 계약은 유지한다.

## Context

Remote에서 페인 스킵은 상단 헤더에, 페인 숨김은 드로어에 있어 관리 위치가 다르다. 워크스페이스 행도 같은 동작을 다른 순서로 제공해 대상을 바꿀 때 조작 위치를 다시 찾아야 한다. 사용자는 두 대상의 스킵·숨김 버튼을 같은 열에 놓고 모바일 목록의 밀도를 유지하는 화면을 승인했다.

최신 main의 ADR-0310은 워크스페이스 숨김을 관리 메뉴에 통합한다. 승인된 직접 숨김 버튼을 반영하려면 이 진입점 결정을 정정해야 한다. 범위는 관리 동작의 표시 위치이며 상태 소유권·인증·API·영속 스키마는 변경하지 않는다.

## Decision

Remote 드로어의 워크스페이스·페인 행은 오른쪽 끝에 스킵·숨김을 같은 순서로 제공하며, 워크스페이스 관리 메뉴를 추가 진입점으로 유지한다.

스킵 상태는 기존 Remote 기기 로컬 제외 집합이 소유하고, 페인 전체 제외와 워크스페이스 제외의 승격·강등 불변식을 유지한다. 숨김은 기존 lease-gated visibility API와 호스트 상태를 사용하며 마지막 표시 워크스페이스 제한·fallback·복원 규칙을 유지한다. 스킵 대상이 아닌 행은 스킵 칸을 비워 숨김 열을 맞춘다.

페인 스킵의 기본 진입점은 상단 헤더에서 드로어로 옮긴다. 기존 선택형 key-bar·floating 스킵 단축 액션과 표시 설정은 유지한다. 워크스페이스의 명시적 관리 버튼은 스킵·숨김 열 앞에 두며 이름 변경·템플릿 저장·숨김 관리 창을 계속 제공한다. 관리 버튼을 포함한 조작부가 행 높이를 늘리지 않도록 밀도를 맞춘다.

## Alternatives Considered

- 숨김을 워크스페이스 관리 메뉴에만 유지: 페인 숨김과 위치가 달라 사용자가 승인한 동일 열 조작을 충족하지 못한다.
- 페인 관리 메뉴에도 숨김·스킵을 통합: 매번 메뉴를 여는 탭이 추가되고 승인된 직접 조작 화면과 다르다.
- 워크스페이스 관리 메뉴 제거: 최신 main의 이름 변경·템플릿 저장 기능을 잃으므로 제외한다.
- 상단 페인 스킵 유지: 목록에서 대상별 관리를 완료할 수 없고 조작 위치 차이가 남는다.

## Consequences

대상을 바꿔도 스킵·숨김 위치가 같아지고 비활성 페인도 드로어에서 바로 제외할 수 있다. 워크스페이스는 관리 메뉴와 직접 숨김 진입점을 함께 제공하는 비용이 있으며 조작부가 한 칸 늘어난다. 모바일에서 버튼 너비·간격·하단 여백을 줄이고 상태 강조를 아이콘 색상으로 제한한다.

모바일 브라우저 테스트로 열 정렬·목록 밀도·스킵 연동·숨김/복원·기존 관리 메뉴를 검증하고 living doc과 생성 번들을 갱신한다. 별도 데이터 마이그레이션은 없다. 관리 동작 증가 또는 터치 오조작이 관찰되면 밀도와 직접 조작 범위를 다시 검토한다.

# 0263. Remote 도구의 상단 스와이프 안내 줄을 제거한다

- Status: Accepted
- Date: 2026-09-22
- Source: 사용자의 Remote 상단 `← Next tool · Close →` 안내 영역 삭제 요청, [api-contracts.md §13 Remote 도구 순환](../architecture/api-contracts.md#remote-도구-순환-adr-0261), [ADR-0261](0261-remote-visible-tool-swipe-cycle.md)
- Partially supersedes: ADR-0261의 안내 줄 표시·제스처 표면 결정. 나머지 도구 순환 계약은 유지한다.

## Context

Remote의 GitHub·Files·Memo 패널은 헤더 아래에 다음 도구와 오른쪽 스와이프 동작을 안내하는 줄을 표시한다. 사용자는 이 영역이 불필요하므로 제거하도록 요청했다. 안내 줄은 모바일 화면 높이를 사용하며, 기존 헤더와 목록에서도 같은 제스처를 시작할 수 있다.

## Decision

**Remote 도구 패널에서 상단 스와이프 안내 줄을 제거하고 기존 헤더·목록 제스처를 유지한다.**

안내 줄의 DOM·스타일·문구 갱신 로직을 삭제한다. 도구 순서, 기기별 설정, 닫기 버튼, 입력·선택 제외 규칙, 초안 보존과 Files Back은 ADR-0261을 그대로 따른다. 안내 줄 대신 편집 본문을 새 제스처 표면으로 사용하지 않는다. API·권한·영속 스키마는 변경하지 않는다.

## Alternatives Considered

- 문구만 비우고 영역 유지: 불필요한 상단 공간을 제거하려는 요구를 충족하지 못한다.
- 표시 토글 추가: 요청되지 않은 설정과 상태를 늘리고 안내 영역의 유지 비용이 남는다.

## Consequences

세 도구의 본문이 안내 줄 높이만큼 넓어진다. 스와이프 동작의 상시 안내와 메모의 추가 제스처 시작 영역은 사라지며, 메모에서는 기존 헤더를 사용한다. 기존 도구 순환·설정 E2E와 실제 화면으로 동작 및 배치를 확인하고 배포용 Remote 번들을 다시 생성한다. 추후 제스처 발견성이 문제가 되면 별도 안내 방식을 검토한다.

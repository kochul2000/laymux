# 0282. 에이전트 훅은 실행 환경별 선택 설치로 관리한다

- Status: Accepted
- Date: 2026-09-29
- Source: 사용자 요구(Settings의 Claude·Codex 연결에서 Windows·WSL별 훅 설치·제거, 미사용 시 기존 휴리스틱 유지), [ADR-0278](0278-codex-status-current-screen.md), [ADR-0280](0280-codex-app-server-process-role.md)
- 관계: ADR-0278의 훅 통합을 제외한 범위를 확장한다. 상태 감지 방식의 선택·소비는 별도 PR에서 결정한다.

## Context

종료 순간에 TUI를 조작해 세션을 알아내는 방법은 입력·화면·키맵 변화의 영향을 받는다. CLI가 제공하는 생명주기 훅으로 세션 정보를 일찍 받을 수 있지만 사용자 CLI 설정을 강제로 수정할 수는 없다. Windows와 각 WSL 배포판은 서로 다른 사용자 홈과 에이전트 설정을 가지며 일부 환경만 통합할 수도 있다.

설치했다고 현재 대화에 훅이 적용된 것은 아니다. CLI의 신뢰 승인·훅 비활성화·실행 버전·이미 열린 세션에 따라 이벤트가 오지 않을 수 있다. 에이전트 설정 전체를 덮어쓰거나 다른 사용자 훅을 삭제해서도 안 된다.

## Decision

**Claude·Codex 훅을 기본 미설치로 제공하고 Settings에서 선택한 호스트와 설정 폴더에 Laymux 소유 항목만 설치·제거한다.**

- 각 환경의 실제 CLI 설정 파일이 설치 상태의 정본이다. Windows(또는 native host)와 개별 WSL 배포판을 독립 대상으로 취급한다. 사용자 기본 설정 폴더를 제시하되 사용자 지정 설정 폴더도 명시적으로 선택할 수 있다.
- Claude의 `settings.json`, Codex의 `hooks.json`에 command 훅을 병합한다. 사용자 항목과 알 수 없는 필드는 보존한다. 설치는 중복 없이 재실행 가능하며 제거는 Laymux가 생성한 command 문자열과 type이 정확히 일치하는 handler만 대상으로 한다. 사용자가 timeout이나 이벤트 위치를 바꾸어도 같은 command는 소유 항목이다.
- 같은 설정 파일의 Laymux 쓰기는 파일 락으로 직렬화한다. 기존 내용을 읽고 검증한 후 백업과 임시 파일을 만들고 원자 교체한다. 손상·예상하지 못한 스키마·동시 외부 변경은 원본을 보존한 채 실패한다. 기존 사용자 전체 설정을 백업으로 되돌리는 제거는 하지 않는다.
- 런타임 의존성을 요구하지 않는 전용 Rust helper를 배포한다. WSL 파일 작업은 지정한 배포판의 기본 사용자로 Linux helper가 수행하고, native는 같은 라이브러리를 사용한다. 배포판 이름·파일 경로를 셸 코드에 보간하지 않는다.
- 훅은 세션 ID·이벤트 종류·실행 귀속 메타데이터만 보고하며 프롬프트·도구 인자·대화 내용은 전송하거나 로그에 남기지 않는다. Laymux 밖에서 실행하면 조용히 종료하고 CLI의 판단·출력을 바꾸지 않는다.
- 수신은 기존 Automation API의 IP allowlist와 dev/release 포트 분리를 따른다. PTY마다 새로 발급한 식별 토큰으로 이전 PTY의 지연 이벤트를 거부한다. 이벤트 수신 사실은 CLI 설치·로그인 완료나 복원 기록의 영속성을 보장하지 않는다.
- 설치·제거는 명시적 즉시 action이다. 일반 Settings 저장·초기화·앱 실행이 훅을 자동 설치하지 않는다. 설치 상태와 실제 세션에서의 수신 상태를 구분한다. Codex 훅 신뢰 확인을 우회하거나 CLI의 전체 훅 비활성 설정을 강제로 해제하지 않는다.
- 미설치·제거·미수신 환경은 기존 휴리스틱 경로를 유지한다. 훅 정보로 상태 판정을 바꾸는 기능은 별도 PR의 선택 설정에 한정한다.

## Alternatives Considered

- 전역 자동 설치: 사용자의 선택과 환경별 독립성을 침해한다.
- 사용자 설정 파일 전체 생성·복원: 기존 훅과 설치 이후 사용자 편집을 잃을 수 있다.
- Python·Node 스크립트: Windows·WSL마다 런타임 존재와 경로를 추가로 관리해야 한다.
- 종료 훅만 사용: 크래시·강제 종료·대화 전환을 신뢰성 있게 관찰하지 못한다. 시작·resume부터 관찰하고 실제 프로세스 검증을 유지해야 한다.

## Consequences

사용자는 통합 정확성과 CLI 설정 변경 사이에서 환경별로 선택할 수 있다. helper 배포와 파일 병합·제거, 설정 폴더·비활성 훅·버전 차이를 검증하는 비용이 추가된다. 기존 훅 보존, 설치·제거 반복, 부분 설치, 손상 파일, 특수문자 경로, Windows·WSL 실제 CLI 이벤트를 검증한다. 이 기능은 호환되는 사용자 기능 추가이므로 다음 기능 릴리스의 버전 영향은 minor다.

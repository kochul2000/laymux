# 0286. 종료 안내의 복원 링크는 설정 명령으로 같은 셸에서 수동 실행한다

- Status: Proposed
- Date: 2026-09-30
- Source: 사용자 요구(CLI 종료 안내 클릭으로 Windows·WSL 세션 재진입), [ADR-0125](0125-configurable-agent-launch-command.md), [api-contracts.md 에이전트 실행 명령](../architecture/api-contracts.md)
- Relationship: ADR-0125의 복원 명령 소유권을 명시적 사용자 클릭으로 확장한다. 자동 복원 귀속 정책은 변경하지 않는다.

## Context

Codex와 Claude는 종료할 때 세션 복원 명령을 출력하지만 사용자는 이를 복사해 옵션을 다시 붙여야 한다. 이미 설정에 복원용 실행 명령과 옵션이 있다. 출력 문자열 자체는 신뢰할 수 없고, Windows와 WSL의 서로 다른 세션 저장소·CWD를 유지해야 한다. 이번 범위는 데스크톱 터미널의 명시적 클릭이며 Remote 표면과 자동 세션 귀속 변경은 포함하지 않는다.

## Decision

**종료 안내의 정형 명령에서 provider와 UUID만 추출하고, 사용자가 클릭하면 현재 provider.command 설정으로 재조립해 출력이 있었던 같은 터미널에 제출한다.**

- 표시와 클릭은 xterm의 추가 링크 provider가 소유한다. Rust OSC 파이프라인에는 파서를 추가하지 않는다. ANSI는 이미 파싱된 셀에서 읽으며 자동 줄바꿈만 결합한다. 정형 명령은 공백을 제외한 줄 전체가 `codex resume <uuid>`, `claude --resume <uuid>`, `grok --resume <uuid>`인 경우다. 추가 옵션·셸 구문·실제 개행으로 나뉜 식별자는 거부한다. Grok는 이 알려진 명령 형식만 지원하며 확인되지 않은 종료 안내 형식을 추정하지 않는다.
- 설정이 실행 옵션의 단일 진실원이다. 클릭 순간 ADR-0125의 정규화 함수로 실행 명령을 도출한다. 원문 명령이나 원문의 옵션은 제출하지 않는다. 자동 복원 설정 `restoreSession`은 수동 클릭을 제한하지 않는다.
- 클릭 순간 동일한 셀 범위와 원문, buffer 종류·폭을 다시 확인한다. 로컬 제어권과 출력 준비가 있고 셸 상태인 경우에만 기존 `write_terminal_input` 경로로 한 번 제출한다. 진행 중인 제출의 중복 클릭은 무시하고 실패 시 알림을 남긴다. 재전송은 하지 않는다.
- 기존 터미널의 셸·프로필·CWD를 사용한다. Windows·WSL 사이에 경로나 세션 ID를 이동시키지 않으며 새 PTY를 만들지 않는다. 수동으로 선택한 ID를 자동 귀속·세션 영속의 증거로 저장하지 않는다.

## Alternatives Considered

- 출력된 명령 그대로 실행: 설정 옵션이 누락되고 셸 주입 문자열을 실행할 위험이 있어 기각한다.
- 새 pane 생성: 실행 중인 셸의 환경과 CWD를 별도로 복제해야 하고 사용자가 원한 즉시 재진입의 위치가 달라져 기각한다.
- Rust에서 출력 힌트로 세션 귀속: 사용자의 선택 없이 출력 텍스트를 PID 귀속 증거로 바꾸므로 기존 자동 복원 불변식과 충돌한다.
- 모든 resume 명령의 임의 옵션 파싱: CLI별 셸 문법을 추가로 지원할 필요가 없다. 알려진 UUID 복원 명령만 처리한다.

## Consequences

- 종료 안내를 클릭하면 사용자가 설정한 옵션으로 바로 재진입하며 Windows·WSL에서 동일한 입력 경로를 사용한다.
- 셸 상태 관찰이 늦으면 클릭은 실행하지 않는다. 이미 입력한 셸 편집 문자열은 일반 입력 제출의 기존 의미를 따른다.
- 종료 안내가 정형 명령과 다른 형태로 변경되면 링크가 생기지 않는다. 실제 출력 근거와 화면 테스트를 추가한 뒤 형식을 확장한다.
- 단위 테스트는 정형 문법·옵션 조합을 검증하고, 화면 테스트는 ANSI·자동 줄바꿈·reflow·오래된 링크 폐기를 검증한다. dev 실기 검증은 기존 Automation API 조작과 WebView 디버깅 포인터 입력 및 스크린샷을 사용한다.
